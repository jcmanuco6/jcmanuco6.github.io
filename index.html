    About

    I build geospatial pipelines and 3D visualization systems that turn raw survey, LiDAR, and municipal parcel data into interactive tools county and state government teams actually use — from CityJSON building models served as OGC 3D Tiles, to automated ETL that keeps property and infrastructure data current without manual re-processing.

    Projects

    • 3D Cadastral Pipeline

      CityJSON → FME → OGC 3D Tiles → CesiumJS. County-scale building models, color-styled by height and year built, with click-to-inspect parcel attributes.

      Case study

    • Spatial ETL Pipeline

      Automated batch geoprocessing and API integrations — raw source data to cloud-ready formats (GeoParquet, 3D Tiles) on a schedule.

      Case study

    • Interactive Analytics Map

      Embedded map application over spatial queries and raster/vector processing notebooks, built for non-GIS stakeholders.

      Case study

    • System Architecture

      Data flow and database schema design for a multi-source geospatial platform — CLI tooling, PostGIS, and cloud storage conversions.

      Case study

    • Reality Capture Workflow

      LiDAR point cloud → mesh → web-ready 3D Tileset. Photogrammetry and building footprint extraction for as-built documentation.

      Case study
