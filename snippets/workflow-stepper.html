  1. 01

    Raw LAZ Ingestion & Ground Filtering

    Ingested raw LAZ tile sets and 2D building vectors; executed automated ground classification and filtering via PDAL and Laspy.

  2. 02

    Normalized Height Extraction

    Programmatically computed building heights above ground by comparing rooftop Z-max values against ground surface models.

  3. 03

    CityJSON LoD1 Generation

    Serialized extracted building volumes into structured LoD1 3D CityJSON prisms using cjio.

  4. 04

    Geometry Validation & Compilation

    Ran automated mesh verification via PyVista (PLY/OBJ) and compiled assets into a unified spatial repository.
