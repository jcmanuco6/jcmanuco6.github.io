# Joan Colon — GIS & Geospatial Data Engineering Portfolio

Production-minded geospatial engineering: automated spatial ETL, county-scale 3D web mapping, and the data pipelines behind reliable GIS. Each case study walks from raw data to a deployed, usable product.

### 🔗 [**View the live portfolio → jcmanuco6.github.io**](https://jcmanuco6.github.io/)

## Key Case Studies

- **[3D Cadastral Digital Twin & Cloud Pipeline](https://jcmanuco6.github.io/projects/cadastral-3d-pipeline/)** — LiDAR → CityJSON LoD1 → Cesium 3D Tiles; county-scale buildings styled by height and year built, with click-to-inspect parcel attributes.
- **[Cadastral Mapping Automation](https://jcmanuco6.github.io/projects/cadastral-mapbook-automation/)** — Containerized spatial ETL moving field inspection data from API to ArcGIS Online hosted feature services.
- **[Maui Commute Traffic Hotspot Analyzer](https://jcmanuco6.github.io/projects/maui-traffic-hotspot/)** — TomTom traffic flow fused with OSMnx road networks to flag AM spillback intersections.
